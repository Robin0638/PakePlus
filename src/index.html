Plan easily, schedule worry-free
Current Version 3.1.0
Now supports China Mobile Jiutian AI Assistant intelligent agent content management
This update optimized several features and fixed many bugs
1. Schedule and Task Management
Schedule and task management is a core function that helps users efficiently arrange time and track task progress.
Search function: Provides date search, allowing users to intuitively view their schedules and conveniently plan short and long-term tasks.
Task creation and classification: Supports creating tasks and classifying them by priority, deadline, item category, etc., ensuring important tasks are not missed.
Time block management: Allows users to divide a day into different time blocks, allocating fixed time periods for each task to improve time utilization.
2. Large Project Planning
The large project planning function aims to help users manage complex projects, ensuring projects progress according to plan and are completed on time.
Project breakdown: Break down large projects into multiple phases or tasks, each phase can be further divided into specific steps.
Milestone setting: Allows users to set key milestones, marking important nodes of the project to ensure the project progresses as planned.
Resource allocation: Supports allocating resources for tasks, such as personnel, time, budget, ensuring reasonable project resource allocation.
Progress tracking: Real-time tracking of project progress, marking tasks as completed, in progress, or not started, helping users adjust plans in a timely manner.
3. Things List Function
The List function is a tool to help users organize and track to-do items, suitable for handling trivial tasks or short-term goals.
List creation: Users can create multiple Lists, such as shopping Lists, to-do Lists, study Lists, etc.
Task checking: Supports task checking function, after completing a task it can be marked as "completed", helping users visually see progress.
Subtask support: Allows adding subtasks to the List, breaking down complex tasks into smaller steps for gradual completion.
Priority marking: Can set priorities for tasks in the List, such as high, medium, low, ensuring important tasks are completed first.
Shared Lists: Supports sharing Lists with others, facilitating team collaboration or family members completing tasks together.
4. Pomodoro Focus Timer
The Pomodoro focus timer function originates from the "Pomodoro Technique" proposed in psychology, helping users improve focus and efficiency through time management.
Pomodoro timing: Set 25 minutes or more customized focus time periods, i.e., a "Pomodoro time", during which users can focus on one task.
Timer reminder: Issues a reminder when the Pomodoro time ends, helping users maintain rhythm.
Focus recording: Records the user's time and completed Pomodoro count, generates statistical data, helping users understand their focus habits.
Distraction blocking: Supports blocking notifications or locking devices, reducing external distractions, ensuring focus.
5. Humanistic Care Function
Smart rest reminder: When users use the app after 10 PM, it will automatically remind users to rest, encouraging users to develop good rest habits
Hydration reminder: Allows users to customize drinking water intervals, automatically reminding users to drink water when the time comes
Dietary care assistant: Reminds users when they haven't eaten at appropriate times, encouraging users to form regular eating habits
6. Mini Tools Function
Users can exchange points to use for one day, the tools are convenient and practical, greatly solving user pain points.
7. Today's Hot Search Module
Users can know what's happening in the world without exiting the software
8. Horoscope Module
Using this module, users can quickly get today's fortune, helping them make travel decisions
9. This Day in History
This module helps users broaden their horizons
